# Social Force Model Simulation - Pedestrian Dynamics
This repo contains our code for our experimental, simulation-based, research on the social force model for pedestrian dynamics.

## Requirements
The only required library cromosim version 2.1.0, and all its dependencies.

The animated simulations are created with ffmpeg which must be installed either with Homebrew on mac:

macOS (using Homebrew):
`{bash}
brew install ffmpeg
`
Linux (Debian/Ubuntu):
`{bash}
sudo apt-get install ffmpeg
`
Windows: Download from FFmpeg's official site and add it to your system PATH.
